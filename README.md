## 💻 API Documentation (Python Bridge)

LV Nexus uses a robust `OptimizerApi` class to bridge the Python backend with the frontend JS:

```python
# Apply a performance profile
api.apply_profile("gaming")  # Options: gaming, development, content, balanced

# Initiate Deep Optimization
api.deep_optimize()

# Flush Physical RAM
api.flush_ram()

# Apply specific Advanced Tweaks
api.apply_advanced_tweak("aero_shake", True)

# Block Telemetry
api.apply_privacy_tweak("telemetry_level", False)
```
